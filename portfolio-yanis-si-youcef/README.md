# Portfolio — Yanis Si Youcef

Projet Next.js prêt pour GitHub et Vercel.

## Mettre les fichiers sur GitHub

1. Décompressez le ZIP.
2. Ouvrez votre repository GitHub.
3. Cliquez sur **Add file**, puis **Upload files**.
4. Glissez tout le contenu du dossier décompressé dans la page GitHub.
5. Cliquez sur **Commit changes**.

N'envoyez pas le ZIP lui-même : envoyez les dossiers `app`, `components`, `lib`, `public` et les fichiers situés à côté.

## Déployer sur Vercel

1. Connectez-vous à Vercel avec GitHub.
2. Cliquez sur **Add New → Project**.
3. Sélectionnez le repository du portfolio.
4. Gardez les réglages proposés par défaut.
5. Cliquez sur **Deploy**.

## Développement local

```bash
npm install
npm run dev
```

Les aperçus Instagram utilisent l'intégration web officielle d'Instagram. Ils doivent être testés sur l'URL Vercel, et peuvent ne pas apparaître dans un fichier HTML local ou si le Reel n'est pas public.
